01 核心能力
🕸 抓包代理一键接管系统代理，HTTP/HTTPS 流量自动捕获；HTTPS 通过自签 CA 中间人解密（Burp 同方案）
📮 发包 Repeater任意请求构造 + 返回包查看 + Burp 原始请求自动解析
🧠 AI 双模型内置 DeepSeek v4-flash / v4-pro，密钥加密存储本机
🛡️ 证据级反幻觉AI 结论必须引用真实流量证据，编造即作废
📊 数据包分析一键分析 → 每个数据包的漏洞类型/严重度/置信度/研判理由
📄 复现报告AI 自动生成复现步骤 / 请求包 / 修复建议
🎯 赏金平台SRC / 众测 / 国际赏金平台导航（补天、HackerOne 等）
📚 知识助手本地渗透手册 + CSDN 知识库双源检索
🔐 授权硬闸门目标不在授权范围 → 拦截 + 全量审计
🖥 独立桌面版31MB 单 exe，脱离浏览器（pywebview）
