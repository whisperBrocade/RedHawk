📖 使用指南
从零开始的简明使用方式，按顺序操作即可。

🚀 快速上手（3 步）

① 配置 AI 模型（可选但推荐）
左侧「AI 模型」→ 填入 DeepSeek API 密钥 → 选择 v4-flash / v4-pro → 保存 → 测试连接
② 登记目标
「目标管理」→ 填名称 + 授权范围（如 *.example.com, 10.0.0.0/24）→ 登记。越权操作会被硬拦截。
③ 开始使用
按下面场景选择功能，所有操作都在左侧任务栏。

🕸 抓包（看流量）

1. 「抓包代理」→ 点「▶ 启动」按钮（按钮会变「■ 停止」+ 绿灯 = 运行中，自动接管系统代理，本机所有应用流量自动进入）
2. 正常上网/使用软件 → 「流量记录」实时显示抓到的数据包（📋 全部 / 🗂 归类 切换查看）
3. 点任意一条数据包 → 查看完整请求/响应报文
4. 想抓 HTTPS 明文：先「🔑 下载 CA 证书」→ 双击 E:\harness work\RedHawk\data\安装CA证书.bat 以管理员运行 → 重启浏览器
5. 用 SwitchyOmega 等插件：代理协议选 HTTP，服务器 127.0.0.1，端口 8888（选 HTTPS 会连不上！）
6. 停止抓包：再点按钮「■ 停止」→ 系统代理自动还原
7. 若浏览器提示 ERR_PROXY_CONNECTION_FAILED：通常是服务重启后代理丢失，点「▶ 启动」重新开启（新版已支持自动恢复）

📊 数据包分析（AI 结果管理）

1. 配置 AI 模型后，在「抓包代理」点「⚡ 一键 AI 抓包分析」
2. 分析完成自动跳转到「数据包分析」面板
3. 详细信息列表：每个数据包的 漏洞类型 / 严重度 / 研判（✅真实·❓待确认）/ 置信度 / 理由
4. 点「查看」展开完整详情：复现步骤 + 请求证据 + 响应证据

📮 发包（手动测试请求）

1. 「发包 Repeater」→ 选方法（GET/POST/...）→ 填 URL
2. 可选：填 Headers（JSON）、Body、或粘贴 Burp 原始请求自动解析
3. 点「🚀 发送」→ 右侧显示返回包（状态/响应头/响应体）

🎯 漏洞扫描（自动化）

1. 「任务扫描」→ 填目标 ID + 选 playbook → 「创建任务」
2. 点「▶ 运行」→ 进度条实时显示（fscan 资产发现 → nuclei 漏洞验证）
3. 完成后：点「🧠 AI 研判」过滤误报 → 「生成报告」/「复现报告」
4. playbook：quick_scan（内网）/ web_recon（公网子域+存活+验证）/ ai_app_scan（AI 应用安全）

⚡ 一键 AI 抓包分析（全自动）

1. 先配置 AI 模型（必须，密钥存本机加密）
2. 抓包产生流量后 → 「抓包代理」面板点「⚡ 一键 AI 抓包分析」
3. 自动完成：读流量 → AI 识别漏洞 → 深度研判 → 生成复现报告 → 跳转数据包分析界面
4. 注意：流量无漏洞时 AI 会返回空结果（正常，不报错）

📚 知识助手

「知识助手」→ 提问（如"内网横向移动思路"）→ 本地手册优先 + CSDN 知识库补充（可点击打开原文）

🧹 常用维护

· 端口被占用/代理启动失败 → 「抓包代理」→「🧹 清理残留进程」
· 服务重启后代理自动恢复（检测系统代理指向 8888 自动拉起）
· 查看所有操作记录 → 「审计日志」
· 主题切换 → 左下角 ☀白 / 🕯暖 / 🌑红黑
· 装新工具 → 命令行 rh plugins install --key 工具名
· 独立桌面版 → 双击 dist\RedHawk.exe（脱离浏览器）
